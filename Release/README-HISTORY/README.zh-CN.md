## 1.20.0 快速字幕与捕获设置

- 在 Apple 模式的主窗口顶部切换 **质量优先 / 快速字幕**。捕获期间的选择会在下次捕获时生效。快速字幕可以更早显示草稿，准确率可能降低。
- 设置 > 权限中的 **开始设置权限** 会检查所选输入和引擎需要的权限，跳过已允许的项目，并在从 macOS 系统设置返回后继续。
- 质量优先和快速字幕会按语言对预先调用一次已就绪的 Apple 翻译引擎。快速字幕还会缩短首个短语的等待时间。
- **屏幕与系统音频录制** 一栏显示 Mac 音频使用的权限。第一条字幕出现前，主窗口会区分等待音频和正在接收音频。

## 1.18.0 新增内容：本地 Hy-MT2 翻译 · Focus Stage 界面 · 悬浮字幕 HUD

- **可选本地 Hy-MT2 1.8B 翻译：** 在引擎中心选择 **Hy-MT2**，并在**设置 > 通用**下载经过校验的 Q4_K_M 权重（1.13 GB），即可通过内置 llama.cpp 在 Mac 上本地翻译 Apple 语音识别字幕，无需 API 密钥或外部翻译服务器。支持下载进度、取消、删除模型、本地预览测试、可选术语标签、近期字幕上下文，以及停止时最长 25 秒等待完成而不保存残缺片段。[设置与限制](../../docs/hymt-local-translation.md)。
- **Focus Stage 主界面与更低实时延迟：** 将语言对选择与互换移至顶部状态栏，900pt 默认窗口（840pt 起）保持底部玻璃控制栏单行展开不被折叠；用带时间戳和实时高亮条的轮次卡片替代重复标签，并隔离音频电平波形视图（`SessionAudioWaveform`），避免音频电平更新触发整个控制栏重绘。
- **分类式引擎与语音中心：** 通过 `全部 / 本地 / 云端` 筛选标签清晰区分本地模型、云端实时翻译和云端转写+本地翻译引擎，并直达模型、译文语音和 API 密钥管理。
- **自适应悬浮字幕与悬停迷你 HUD：** 提供`磨砂深色`（默认）、`影院深色`和`透明`背景样式，确保在白色幻灯片和视频上方依然清晰；悬停即可暂停/继续、复制最新字幕、切换显示模式、调节字号（`A-`/`A+`）、切换背景并关闭。
- **菜单栏控制中心 · 记录库搜索导出 · 术语标签：** 菜单栏弹窗改版为带 `电脑音频 / 麦克风` 快速切换的 2×2 磁贴网格；记录库新增搜索、类型筛选与 Markdown（`.md`）/纯文本（`.txt`）导出；设置页新增术语标签编辑器与 API 密钥数量徽章。
- **稳定性修复：** Azure MAI 菜单栏停止等待最终结果并过滤未定稿原文；EmbeddingGemma 修复实时采集结束后重新检测本地模型及音频读取错误提示。

## 英语音频本地转写（自 1.17.0 起）

- **可选文件转写：** 在设置 > 通用 > EmbeddingGemma 2 文件转写（实验）中使用。需要 Apple Silicon 和 macOS 27 及以上；应用整体最低要求仍为 macOS 26。仅限英语音频，最长60分钟／2 GB。与实时字幕独立运行，不恢复标点或大小写，不翻译音频，也不识别说话人。
- **工作原理：** 固定的音频编码器生成随时间变化的表征，训练后的 reader 将其映射到英语单词嵌入，每个时刻选择单词或 blank。CTC 解码合并连续重复标签并移除 blank，生成文本。原实验的代码和 reader 权重未公开，因此使用独立公开复现的 reader v2。
- **明确下载与完整性校验：** 仅在点击下载模型时，从固定的 Hugging Face revision 获取约935 MB文件。安装完成前校验文件大小及 SHA-256。安装至少需要2 GiB可用空间，本地编译也会占用空间。无需 API 密钥，此选项不上传音频或转写结果。
- **使用与导出：** 先停止实时采集，下载模型、选择英语音频，再开始本地转写。提供进度与取消功能，可复制结果或保存 UTF-8 文本。取消后会等待当前模型调用完成，再丢弃结果。显示本次音频时长，以及包含解码和模型加载的处理时间。
- **实验精度与速度：** 口音、噪声、专有名词及固定词表外的词会影响结果。首次模型加载可能更慢。原实验声称1小时音频约13秒的速度，不是 AirTranslate 的性能保证。

[方法、设置与限制](../../docs/embeddinggemma-transcription.md) · [AirTranslate 1.17.0 发布](../GITHUB-RELEASE-1.17.0.md)。

## 继续提供的字幕与翻译改进

**1.16.0 引入的改进**继续提供，包括转写稳定性、重复翻译处理、字幕阅读、Apple 翻译选项、可选 Jev 候选选择及仅悬浮模式窗口控制。以下为保留功能，不是1.17.0的新修复。

- **仅悬浮模式启动与控制：** 空闲时启动采集，暂停时恢复，并在进入运行状态后最小化主窗口。启动失败时保留主控制界面。菜单栏和应用菜单也支持开始、停止、暂停与恢复。
- **上一条字幕显示：** 在当前字幕旁短暂保留上一条字幕，最多一个文本块、两行，持续8秒，并遵循“减少动态效果”设置。
- **悬浮字幕渲染：** 保持当前字幕的位置，取消每次替换时重复的淡入淡出。复用大小受限的布局，避免反复处理全部累积转写。主窗口最小化时跳过字幕显示工作，语音识别与翻译继续运行。
- **Apple 转写与翻译流程：** 保留周围识别上下文。即使没有单独的最终文本事件，也会在切换到下一次发言时保留 Apple 已确认的片段，防止上一段文本在此过程中丢失或重复。
- **减少重复翻译：** 临时转写与最终转写相同时复用正在进行的翻译，同一结果不会重复应用。
- **保护最终字幕与新会话：** 修正后的最终文本优先于过时的临时翻译。已停止会话的迟到结果或错误不会覆盖新会话；不同发言中重复相同表达时，仍保留正确顺序。
- **短转写处理：** 持续变化的短语会在最后一次文本变化后稳定时翻译，上下文充足的文本可更早处理。仅含标点的结果不会触发翻译。
- **阅读历史字幕并保留位置：** 阅读较早字幕时暂停自动滚动，返回最新字幕后恢复跟随。主窗口最小化或隐藏后仍保留阅读位置。
- **减少已关闭字幕的处理：** 关闭悬浮字幕后停止显示定时器和布局处理，转写与翻译继续运行。
- **重新打开悬浮字幕：** 无需重新翻译即可恢复最新文本，并防止临时原文重复。原文被修正后，旧译文不会超过保留时间继续显示。
- **恢复主窗口：** 退出仅悬浮模式时，只恢复由该模式最小化的窗口，也能处理最小化过程中关闭字幕的情况。用户此前自行最小化的窗口会单独保留。
- **采集状态与菜单控制：** 主界面、菜单栏和键盘操作统一显示准备、结束处理和重连状态及可用操作。菜单之间也统一字幕显示模式和字体大小控制。
- **实验性 Jev 候选选择：** 默认关闭。在同时使用 Apple 转写与翻译时，可从最终识别候选中选择要翻译的文本。启用后，会使用保存在 Keychain 中的用户密钥，将候选文本及之前最多6段转写上下文（1,000 UTF-8 字节）直接发送给 TypeSafe。每次请求增加 API 用量及最多1.2秒的响应等待。无候选、不确定、错误或超时均保留原文，不保证准确率提升。[设置与数据处理](../../docs/apple-translation-options.md)。
- **Apple 翻译质量与术语保留：** macOS 26.4 及以上可选择实时（默认）或质量优先，并注册需要保持拼写的术语。质量优先可能耗时更长，取决于 Apple 模型的可用性。某语言对失败后会使用实时翻译，直到重启应用。若注册术语被更改，相关片段保留原文。仅适用于 Apple 文本翻译。
- **macOS 27 音频输入兼容性：** 保留现有16 kHz 单声道路径，同时将不同 PCM 输入格式转换为 Apple 语音识别所需格式。
- **源码构建要求：** 需要包含 macOS 27 SDK 的 Xcode 27 及 Swift 6.4 或更高版本。分发应用仍支持 macOS 26 及以上。

请在设置 > API 密钥 > Qwen 中输入 **阿里云新加坡 API 密钥**。Qwen3.8 LiveTranslate 还需要工作空间 ID；Qwen Audio 3.1 Realtime Plus 和 Filetrans 仅使用密钥。密钥单独保存在 macOS Keychain 中，开始捕获后会将所选实时音频直接发送到阿里云新加坡。在设置 > 通用中，可选择默认模型 `qwen3.8-livetranslate-flash-realtime` 或 `qwen-audio-3.1-realtime-plus`。Qwen Audio 3.1 Realtime Plus 是接收 AirTranslate 翻译指令的全双工实时语音对话模型；Qwen3.8 LiveTranslate 是专用实时翻译模型。**语音输出为可选项，默认关闭**。请在 Model Studio 中查看当前 Qwen Audio 价格。

设置 > 通用中的 `qwen-audio-3.1-asr-flash-filetrans` 用于异步转写音频文件。**仅接受公开的 HTTPS 音频 URL**；QwenCloud 会从 URL 获取音频，此流程不会上传本地音频文件。请只分享你有权发送给提供方的音频。参见 [Qwen 设置与价格](../../docs/qwen-livetranslate.md)。真实账户认证、计费、翻译和转写质量及延迟尚未验证。

**分类式引擎与语音中心**支持按 `全部 / 本地 / 云端` 筛选，灰色区分缺少密钥的云端提供方并直达设置与 API 密钥页面，信息图标说明模型及其计费依据。**OpenAI 语音统一翻译与原文转写**，并保留语言和输出偏好；译文语音模型使用单独的选择器。

**自适应悬浮字幕**提供`磨砂深色`（默认）、`影院深色`和`透明`背景，以及悬停迷你 HUD（暂停/继续、复制、切换显示模式、`A-`/`A+` 字号、切换背景与关闭）。可在设置中调整五种文字样式、字体、颜色、宽度、行距、顺序及示例预览，通过主界面、菜单栏或 ⌘⇧C 切换显示。

**Qwen 停止前会等待最终字幕**。空的最终响应会撤回临时字幕，Qwen 记录仅保存已确认的结果，包括定期保存。Apple Mode 仍为默认模式，记录文件保存仍需主动启用。

**可以选择译文语音输出模型**。在设置或主工作区单独的译文语音选择器中选择 Apple 系统语音、Gemini 3.8 Flash TTS、Flash-Lite TTS 或 MAI Voice 2.1 / Flash。实时模式下也会保存此选择，但仅用于文本翻译；实时提供方继续使用自己的原生音频。Gemini TTS 会使用你的 Gemini 密钥，只将稳定的译文文本发送给 Google。

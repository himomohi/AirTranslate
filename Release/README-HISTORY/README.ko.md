## 1.20.0 빠른 자막과 캡처 설정

- Apple 기본 모드 상단에서 **품질 우선 / 빠른 자막**을 전환할 수 있습니다. 캡처 중 변경은 다음 캡처부터 적용됩니다. 빠른 자막은 초안을 일찍 표시하며 정확도가 낮아질 수 있습니다.
- 설정 > 권한의 **권한 설정 시작**은 선택한 입력과 엔진에 필요한 권한을 확인합니다. 허용된 권한을 건너뛰고, macOS 시스템 설정에 다녀온 뒤 이어서 설정할 수 있습니다.
- 품질 우선과 빠른 자막은 준비된 Apple 번역 엔진을 언어쌍별로 한 번 미리 호출합니다. 빠른 자막은 첫 짧은 구절의 대기 시간도 줄입니다.
- **화면 및 시스템 오디오 기록** 행에 PC 소리에 사용하는 권한이 표시됩니다. 메인 창은 첫 자막 전에 **PC 소리 대기 중**과 **PC 소리 수신 중**을 구분합니다.

## 1.18.0 주요 변경: 로컬 Hy-MT2 번역 · Focus Stage UI · 플로팅 자막 HUD

- **선택형 로컬 Hy-MT2 1.8B 번역:** 엔진 허브에서 **Hy-MT2**를 고른 뒤 **설정 > 일반**에서 검증된 Q4_K_M 모델(1.13 GB)을 다운로드하면 API 키나 외부 번역 서버 없이 Mac에서 바로 번역합니다. 다운로드 진행·취소·삭제·문장 미리보기 확인, 이름·전문 용어 칩, 직전 완료 자막 문맥, 중지 시 최대 25초 대기 드레인(불완전 조각 저장 제외)을 지원합니다. [설정과 제한](../../docs/hymt-local-translation.md).
- **Focus Stage 메인 창 & 저지연 웨이브폼 격리:** 언어 선택·스왑을 상단 스테이지 헤더로 옮기고 900pt 기본 창 폭(840pt 이상)에서도 하단 글래스 콘솔 바가 접히지 않게 정리했습니다. 반복 라벨을 없앤 타임스탬프 턴 카드와 라이브 액센트 바를 적용하고, 오디오 레벨 웨이브폼(`SessionAudioWaveform`)을 분리해 실시간 음성 갱신 시 콘솔 바 전체 재계산을 방지했습니다.
- **카테고리형 엔진·음성 허브:** `전체 / 온디바이스 / 클라우드` 필터와 함께 온디바이스·클라우드 실시간 번역·클라우드 전사+로컬 번역 섹션을 분리해 모델, 번역 음성, API 키 관리로 바로 이동할 수 있습니다.
- **어댑티브 플로팅 자막 & 호버 미니 HUD:** `다크 글래스`(기본값), `시네마 다크`, `투명` 배경 스타일로 밝은 화면 위에서도 선명한 대비를 유지하며, 자막 위에 마우스를 올리면 일시정지·복사·표시 모드 순환·글자 크기(`A-`/`A+`)·배경 전환·닫기 미니 HUD가 나타납니다.
- **컨트롤 센터 메뉴바 · 기록 검색/내보내기 · 용어집 칩 에디터:** 메뉴바 팝오버를 `PC 소리/마이크` 전환 포함 2×2 타일로 개편했고, 저장된 기록에서 검색·필터 및 Markdown(`.md`)/텍스트(`.txt`) 내보내기를 지원하며, 설정에 용어집 칩 에디터와 API 키 개수 배지를 추가했습니다.
- **안정성 수정:** Azure MAI 캡처 메뉴 중지 드레인 및 미완성 초안 제외, EmbeddingGemma 캡처 종료 후 모델 재확인 및 손상·누락 오디오 복구 안내를 개선했습니다.

## 영어 파일 로컬 전사 (1.17.0부터)

- **선택형 파일 전사:** 설정 > 일반 > EmbeddingGemma 2 파일 전사 (실험)에서 사용합니다. Apple Silicon·macOS 27 이상이 필요하며 앱 자체의 최소 요구 사항은 macOS 26입니다. 영어 음원 전용, 최대 60분/2GB이고 실시간 자막과 별도로 동작합니다. 문장부호·대소문자 복원, 음원 번역, 화자 구분은 제공하지 않습니다.
- **작동 방법:** 고정된 오디오 인코더가 시간별 표현을 만들고, 학습된 reader가 이를 영어 단어 임베딩과 연결해 각 시점의 단어 또는 blank를 고릅니다. CTC 디코딩이 연속 중복과 blank를 정리해 문장을 만듭니다. 원 실험의 코드·reader 가중치는 공개되지 않아 독립 공개 재현의 reader v2를 사용합니다.
- **명시적 모델 다운로드와 무결성:** 모델 다운로드를 누를 때만 고정된 Hugging Face revision에서 약 935MB를 받습니다. 설치 완료 전 파일 크기와 SHA-256을 검사합니다. 설치에는 2GiB 이상의 여유 공간이 필요하며 로컬 컴파일에도 공간이 사용됩니다. API 키는 필요하지 않고 음원·전사 결과를 업로드하지 않습니다.
- **사용과 내보내기:** 실시간 캡처를 종료하고 모델을 받은 뒤 영어 음원을 선택해 로컬 전사 시작을 누르세요. 진행률·취소를 제공하며 결과를 복사하거나 UTF-8 텍스트로 저장할 수 있습니다. 취소하면 진행 중 모델 호출이 끝난 뒤 결과를 버립니다. 이번 실행의 음원 길이와 디코딩·모델 로딩을 포함한 처리 시간을 표시합니다.
- **실험적 정확도와 속도:** 억양·잡음·고유명사·단어 목록 밖의 표현에 따라 결과가 달라집니다. 첫 모델 로딩에는 더 오래 걸릴 수 있습니다. 원 실험의 1시간 약 13초 주장은 AirTranslate의 성능 보장값이 아닙니다.

[방법·설정·제한 안내](../../docs/embeddinggemma-transcription.md) · [AirTranslate 1.17.0 릴리즈](../GITHUB-RELEASE-1.17.0.md).

## 유지되는 자막·번역 개선

**1.16.0부터 제공하는 개선**을 계속 사용할 수 있습니다. 전사 안정성, 중복 번역 처리, 자막 읽기, Apple 번역 옵션, 선택형 Jev 후보 선택과 플로팅 전용 창 제어가 여기에 포함됩니다. 아래 항목은 유지되는 기능이며 1.17.0의 신규 수정 사항이 아닙니다.

- **플로팅 전용 시작과 제어:** 대기 중이면 캡처를 시작하고 일시정지 중이면 재개한 뒤, 실행 상태가 되면 메인 창을 최소화합니다. 시작에 실패하면 메인 제어 화면을 유지합니다. 메뉴 막대와 앱 메뉴에서도 시작·중지와 일시정지·재개를 사용할 수 있습니다.
- **이전 자막 표시:** 현재 자막과 함께 직전 자막 한 블록을 최대 두 줄로 8초 동안 표시하며 동작 줄이기 설정을 따릅니다.
- **플로팅 자막 렌더링:** 현재 자막의 위치를 유지하고 반복 교체 페이드를 없앴습니다. 제한된 레이아웃을 재사용하고 누적 전사 전체를 반복 가공하지 않습니다. 메인 창 최소화 시 표시 작업을 건너뛰며 음성 인식과 번역은 계속됩니다.
- **Apple 전사·번역 흐름:** 주변 인식 문맥을 유지하고, 별도 최종 텍스트 이벤트 없이 이전 구간이 확정된 경우에도 다음 발화로 넘어갈 때 해당 구간을 보존합니다. 이 과정에서 이전 문장이 누락되거나 중복되는 문제를 방지합니다.
- **중복 번역 감소:** 임시 전사와 확정 전사가 같으면 진행 중 번역을 재사용하고 같은 결과를 두 번 반영하지 않습니다.
- **확정 자막과 새 세션 보호:** 수정된 확정 문장이 오래된 임시 번역을 대체합니다. 중지한 세션의 늦은 결과·오류가 새 세션을 덮지 않으며, 서로 다른 발화에서 같은 표현을 반복해도 순서를 유지합니다.
- **짧은 전사 처리:** 계속 바뀌는 짧은 구절은 마지막 텍스트 변경 후 안정화될 때 번역하고, 문맥이 충분해지면 대기를 줄입니다. 구두점만 있는 결과는 번역하지 않습니다.
- **과거 자막 읽기와 위치 유지:** 이전 자막을 읽는 동안 자동 스크롤을 멈추고 최신 자막으로 돌아오면 다시 따라갑니다. 메인 창을 최소화하거나 가렸다가 돌아와도 읽던 위치를 유지합니다.
- **닫힌 자막창의 작업 감소:** 플로팅 자막을 닫으면 표시용 타이머와 레이아웃 작업을 중단하며 전사·번역은 계속합니다.
- **플로팅 자막 다시 열기:** 재번역 없이 최신 텍스트를 복원하고 임시 원문 중복을 방지합니다. 원문이 교정되면 오래된 번역이 유지 시간을 넘겨 남지 않도록 합니다.
- **메인 창 복원:** 플로팅 전용 모드가 최소화한 창만 복원하고, 최소화 도중 자막을 닫는 경우도 처리합니다. 사용자가 미리 최소화한 창은 구분합니다.
- **캡처 상태와 메뉴 제어:** 메인 화면·메뉴 막대·키보드에서 준비·종료 처리·재연결 상태와 가능한 동작을 일치시켰습니다. 자막 표시 모드와 글자 크기 제어도 메뉴 간에 통일했습니다.
- **실험적 Jev 후보 선택:** 기본값은 꺼짐입니다. Apple 전사와 번역을 함께 사용할 때 확정 인식 후보 중 하나를 골라 번역할 수 있습니다. 활성화하면 후보 텍스트와 앞선 최대 6개 전사 구간(1,000 UTF-8 바이트)을 Keychain에 저장한 사용자 키로 TypeSafe에 직접 전송합니다. API 사용량과 요청당 최대 1.2초의 응답 대기가 추가됩니다. 후보 없음·불확실·오류·시간 초과 시 원문을 유지하며 정확도 향상은 보장하지 않습니다. [설정과 데이터 처리](../../docs/apple-translation-options.md).
- **Apple 번역 품질과 용어 보존:** macOS 26.4 이상에서 실시간(기본값) 또는 품질 우선을 선택하고 표기를 유지할 용어를 등록할 수 있습니다. 품질 우선은 더 오래 걸릴 수 있으며 Apple 모델 가용성에 따라 달라집니다. 실패하면 해당 언어쌍은 앱 재시작까지 실시간 번역을 사용합니다. 등록 용어가 바뀌면 해당 구간을 원문으로 유지합니다. Apple 텍스트 번역에 적용됩니다.
- **macOS 27 오디오 입력 호환성:** 기존 16 kHz 모노 경로를 유지하면서 다른 PCM 입력 형식을 Apple 음성 인식에 맞게 변환합니다.
- **소스 빌드 요구사항:** macOS 27 SDK가 포함된 Xcode 27과 Swift 6.4 이상이 필요합니다. 배포 앱은 macOS 26 이상에서 실행됩니다.

설정 > API 키 > Qwen에 **Alibaba Cloud 싱가포르 API 키**를 입력하세요. Qwen3.8 LiveTranslate는 워크스페이스 ID도 필요하지만 Qwen Audio 3.1 Realtime Plus와 Filetrans는 키만 사용합니다. 키는 macOS Keychain의 전용 항목에 저장하며, 캡처를 시작하면 선택한 실시간 오디오를 Alibaba Cloud 싱가포르로 직접 전송합니다. 설정 > 일반에서 기존 기본 모델 `qwen3.8-livetranslate-flash-realtime` 또는 `qwen-audio-3.1-realtime-plus`를 선택할 수 있습니다. Qwen Audio 3.1 Realtime Plus는 AirTranslate의 번역 지시를 받는 양방향 실시간 음성 대화 모델입니다. Qwen3.8 LiveTranslate는 전용 실시간 번역 모델입니다. **음성 출력은 선택 사항이며 처음에는 꺼져 있습니다**. Qwen Audio 요금은 Model Studio에서 확인하세요.

설정 > 일반의 `qwen-audio-3.1-asr-flash-filetrans`는 비동기 파일 전사 도구입니다. **공개 HTTPS 오디오 URL만 지원**하며 QwenCloud가 URL에서 오디오를 가져옵니다. 이 흐름은 로컬 파일을 업로드하지 않습니다. 제공자에게 보낼 권한이 있는 오디오만 공유하세요. [Qwen 설정·요금 안내](../../docs/qwen-livetranslate.md)를 참고하세요. 실제 계정 인증·과금·번역·전사 품질·지연은 미검증입니다.

**카테고리형 엔진·음성 허브**는 `전체/온디바이스/클라우드` 필터를 제공하고 키가 없는 클라우드 제공자를 구분하며 설정·API 키 화면으로 바로 연결합니다. 정보 아이콘에서 모델과 요금 기준을 확인할 수 있습니다. **OpenAI 음성은 번역과 원문 전사를 하나로 통합**하고 언어·출력 선호를 유지하며, 번역 음성 모델은 별도 선택기에서 선택합니다.

**어댑티브 플로팅 자막**은 `다크 글래스`(기본값), `시네마 다크`, `투명` 배경 스타일과 마우스 hover 시 나타나는 미니 HUD(일시정지·복사·표시 모드 순환·`A-`/`A+`·배경 전환·닫기)를 제공합니다. 다섯 글자 스타일과 글꼴·색상·폭·줄 간격·배치·샘플 미리보기는 설정에서 조절하고, 메인 화면·메뉴바·⌘⇧C로 표시 여부를 바꿉니다.

**Qwen 중지 전에 최종 자막 수신을 기다립니다**. 빈 최종 응답은 임시 자막을 철회하고, 주기적 저장을 포함한 Qwen 기록에는 확정 결과만 남깁니다. Apple 기본 모드와 기록 파일 저장의 선택 사용 정책은 유지합니다.

**번역 음성 출력 모델을 선택할 수 있습니다**. 설정 또는 메인 화면의 별도 번역 음성 선택기에서 Apple 시스템 음성, Gemini 3.8 Flash TTS, Flash-Lite TTS 또는 MAI Voice 2.1·Flash를 고릅니다. 실시간 모드에서도 선택은 저장되지만 텍스트 번역에서만 사용하며, 실시간 제공자는 자체 음성을 계속 사용합니다. Gemini TTS는 안정된 번역 텍스트만 Google에 보냅니다.

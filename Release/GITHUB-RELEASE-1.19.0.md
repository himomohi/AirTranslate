# AirTranslate 1.19.0

The bottom-left corner of the main window now shows your installed version. Select it to see the build number and check for the latest stable release.

When an update is available, choose **Download Update**. AirTranslate checks the DMG’s SHA-256 digest against GitHub’s release metadata. Choose **Open Installer**, quit AirTranslate, and drag the new app to **Applications**.

## Compatibility and distribution

- Requires **macOS 26 or later**. The optional EmbeddingGemma file transcription feature requires Apple Silicon and macOS 27 or later.
- DMG and ZIP packages are ad-hoc signed and unnotarized. See the [installation guide](https://github.com/himomohi/AirTranslate/blob/master/docs/GETTING-STARTED.md).
- Install this release from GitHub to get in-app update checks for future releases.

# Issue #18 플로팅 자막 사용자 설정

관련 이슈: https://github.com/himomohi/AirTranslate/issues/18

진행 순서: 기존 Nari·API 키 UI 작업을 1.9.0으로 먼저 게시한 뒤, 이 개선을 1.9.1/build191로 별도 배포한다. 1.9.0 게시·CI·원격 배포 파일 검증은 완료했다.

## 문제와 수용 기준

기존 창은 높이가 자막 내용에 고정되어 있고 글자 크기는 네 프리셋이다. 동영상·라이브 방송 배치에 맞는 박스와 색상 설정을 제공한다.

| 요구 | 수용 기준 | 검증 |
| --- | --- | --- |
| 창 크기 | 가로·세로 조절, 이동·크기 조절 안내, 화면 범위 제한 | 실제 앱 드래그·크기 비교, 경계 로직 회귀 검사 |
| 글자 크기 | 기존 프리셋 보존 및 세밀한 사용자 조절, 줄바꿈 계산 반영 | 이전 설정 복원·범위·formatter 검사, 미리보기와 실제 창 |
| 색상·투명도 | 글자·배경 색상과 배경만의 투명도 | 실제 설정·미리보기·창 확인, 직렬화와 유효값 검사 |
| 저장·복원 | 재오픈/재실행 후 유지, 명시적인 기본값 복원 | 독립 UserDefaults 테스트, 실제 재실행 |
| 기존 동작 | 원문/번역 표시·줄 수·안정화 유지, 네 언어 레이블·키보드 조작 | 기존 회귀 검사 및 설정 UI/AX |
| 배포 | 버전·네 언어 의미·노트·ZIP/DMG/checksum 일치 | 테스트·보안 게이트 후 게시 및 재다운로드 검증 |

## 범위와 검증 경계

음성 인식·번역 공급자 및 기본 엔진은 변경하지 않는다. 실제 클라우드 인증이나 오디오 전송은 이번 UI 개선의 수용 기준이 아니다. 사용자 콘텐츠를 새 네트워크 대상으로 전송하지 않는다. 임의 색상 선택은 사용자가 조절하며 저대비를 자동으로 접근성 적합으로 간주하지 않는다. 실제 VoiceOver 낭독 여부는 별도 기록한다.

구현 책임은 caption_implementation, 문서·버전은 release_preparation, 테스트·보안·최종 UI·공개 결과 통합은 릴리즈 하네스로 나눈다. 최종 동작과 증거는 1.9.1 게이트 보고서에 기록한다.

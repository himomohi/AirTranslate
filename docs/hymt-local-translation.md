# 로컬 Hy-MT2 번역

1. 메인 창의 모드 목록 또는 설정 → 일반에서 **Hy-MT2**를 선택합니다.
2. 설정 → 일반에서 **모델 다운로드 (1.13GB)**를 누릅니다. 설치에는 최소 2.5GB의 빈 공간이 필요합니다. 진행 중 취소할 수 있습니다.
3. 모델 준비가 끝나면 같은 화면의 **로컬 번역 확인**에서 선택한 언어쌍으로 문장을 번역할 수 있습니다.
4. PC 소리 또는 마이크 캡처를 시작하면 Apple 음성 인식 결과를 Hy-MT2가 번역합니다. Apple 음성 인식팩과 캡처 권한은 기존 흐름대로 필요합니다. Apple 번역 언어팩은 요구하지 않습니다.
5. 제품명·약어가 많은 영상은 **이름·전문 용어**에 정확한 표기를 한 줄에 하나씩 등록할 수 있습니다(최대 32개, 각 80자). 용어와 앞선 완료 자막 최대 두 개를 번역 문맥으로 사용합니다. 용어는 캡처를 중지한 상태에서 변경합니다.

번역은 앱 안에서 실행하며 API 키·서버 주소·외부 런타임 설치가 필요하지 않습니다. 이 옵션은 원문과 번역을 외부로 보내지 않습니다. 모델 다운로드만 Hugging Face에 연결합니다. 별도로 활성화한 Jev 후보 선택이나 외부 음성 합성 서비스의 데이터 처리는 해당 옵션의 설정을 따릅니다. 기존 기본 모드는 유지됩니다.

제공 모델은 Tencent의 **Hy-MT2-1.8B-Q4_K_M.gguf**입니다. 7B·30B 모델과 특수 STQ 양자화는 이번 옵션에 포함하지 않습니다. 앱은 고정 revision `a0c709d9fac510f2c807aa3af52872340dc37a4a`의 파일 크기(1,133,080,448바이트)와 SHA-256을 검사한 뒤 설치합니다. 모델은 사용자 Application Support의 `AirTranslate/Models/HyMT2`에 저장합니다. 삭제 버튼은 이 모델의 설치 폴더만 제거하며, 나중에 다시 다운로드할 수 있습니다.

llama.cpp b12317은 앱 번들에 포함됩니다. 모델을 세션 내에서 재사용하고 요청마다 내부 대화 상태를 비운 뒤 필요한 자막 문맥만 다시 전달합니다. 기본 번역은 같은 입력에서 결과가 흔들리지 않도록 결정적 디코딩을 사용합니다. 첫 번역에는 모델 로딩 시간이 추가됩니다. 처리 속도와 메모리 사용량은 Mac과 입력에 따라 달라지며, 클라우드 엔진과 동일한 지연이나 정확도를 보장하지 않습니다. 기존 자막 분할 정책에 따라 문장 단위로 번역합니다.

**중지**를 누르면 새 음성 입력을 닫고 화면에 도착한 마지막 원문과 대기 중인 번역을 최대 25초 동안 마무리합니다. 완료된 번역만 저장하며, 시간 초과·오류·앱 종료로 끝내지 못한 번역 조각은 저장하지 않습니다. 아직 음성 인식 결과로 도착하지 않은 오디오의 끝부분까지 복구하는 기능은 아닙니다. 취소는 현재 native 연산 구간이 끝난 뒤 반영될 수 있습니다.

용어 등록은 Apple 음성 인식 원문을 바꾸지 않습니다. 등록된 용어 중 대문자 약어를 포함하는 이름은 영어 인식 결과의 발음 형태가 일치할 때 **번역 입력에서만** 정확한 표기로 정리합니다. 문장 부호를 넘는 치환과 여러 등록 용어에 동시에 해당하는 치환은 하지 않습니다. 예를 들어 기술 영상에서 `Apps SDK`를 등록하면 `Abscess decay`와 같은 오인식의 번역을 개선할 수 있지만, 다른 분야의 동음 표현까지 정확히 구분하지는 못합니다. 해당 영상과 관련된 용어만 등록하고 결과를 확인하세요. 용어를 비워 두면 이 표기 정리를 적용하지 않습니다.

지원 언어 선택은 AirTranslate의 기존 목록을 사용합니다. 긴 단일 입력이 모델의 문맥 또는 출력 한도를 넘으면 오류를 표시합니다. 설정의 문장 확인은 실제 음성 인식 정확도·오디오 캡처 권한 검증과 구분됩니다.

공식 근거: [Hy-MT2](https://github.com/Tencent-Hunyuan/Hy-MT2), [고정 모델 파일](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF/tree/a0c709d9fac510f2c807aa3af52872340dc37a4a), [llama.cpp b12317](https://github.com/ggml-org/llama.cpp/releases/tag/b12317).

# Feature Map

| Feature | Entry point | Core files and symbols | Data and external dependency | Verification |
| --- | --- | --- | --- | --- |
| Provider and realtime model selection | Main window bottom-right provider/model picker; Settings > General | `ProcessingModePicker`, `ProcessingEngine`, `ProcessingEngine+Selection`, `TranslationSessionStore`, provider model enums | Model choices follow the active provider. Qwen3.8 uses the workspace ID; Qwen Audio 3.1 Realtime Plus uses the API key and Qwen Audio WebSocket protocol. Retired Nari free-beta models are omitted from the main picker. | `swift build`; `swift test --filter ProcessingModePickerTests` |
| Qwen realtime model selection | Main window bottom-right provider/model picker; Settings > General | `QwenTranslationModel`, `QwenRealtimeTranslationService`, `TranslationSessionStore`, `QwenCopy` | Microphone or Mac audio is sent to Alibaba Cloud Singapore after capture starts. Qwen3.8 uses the workspace ID; Realtime Plus authenticates with the API key and Qwen Audio WebSocket protocol. | `swift test --filter Qwen`; `./script/build_and_run.sh --verify` |
| Qwen Audio Filetrans | Settings > General > Qwen Audio File Transcription | `QwenAudioFileTranscriptionView`, `QwenAudioFileTranscriptionService` | A user-provided public HTTPS audio URL is sent to QwenCloud. QwenCloud fetches the file and returns an asynchronous task result. This workflow does not upload local audio files. | `swift test --filter QwenAudioFileTranscriptionServiceTests`; `./script/build_and_run.sh --verify` |
| Translated speech model selection | Main window bottom-right provider/model picker; Settings > General > Voice Output for text-translated output | `SpeechSynthesisModel`, `ProcessingModePicker`, `GeminiSpeechOutput`, `TranslationSessionStore.speakTranslatedDeltaIfNeeded` | Apple system speech remains the default. When a Gemini 3.8 TTS model is selected, only stable translated text is sent to the Gemini Interactions API using the Gemini API key stored in Keychain. Realtime providers keep their native audio output. | `swift build`; Gemini Keychain/API/audio playback require a configured key and runtime verification |
| Single running app instance | Finder, Dock, and the local build/run launcher | `LSMultipleInstancesProhibited`, `script/write_info_plist.sh`, `script/build_and_run.sh` | Launch Services permits only one AirTranslate instance; the local builder does not kill or force-spawn an instance and stops before replacing the app bundle if AirTranslate is already running. | `script/verify_packaging_permissions.sh`; inspect generated local and release Info.plists |

# Feature Map

| Feature | Entry point | Core files and symbols | Data and external dependency | Verification |
| --- | --- | --- | --- | --- |
| Provider and realtime model selection | Main window bottom-right provider/model picker; Settings > General | `ProcessingModePicker`, `ProcessingEngine`, `ProcessingEngine+Selection`, `TranslationSessionStore`, provider model enums | Model choices follow the active provider. Gemini Live models are kept separate from Gemini TTS in the model selector. Qwen3.8 is a translation model; Qwen Audio 3.1 is a realtime voice-conversation model that receives translation instructions. Azure MAI submits sequential 5-second REST transcription chunks. | `swift build`; `swift test --filter ProcessingModePickerTests`; [model capability audit](model-capability-classification-2026-09-24.md) |
| Qwen realtime model selection | Main window bottom-right provider/model picker; Settings > General | `QwenTranslationModel`, `QwenRealtimeTranslationService`, `TranslationSessionStore`, `QwenCopy` | Microphone or Mac audio is sent to Alibaba Cloud Singapore after capture starts. Qwen3.8 uses a dedicated realtime translation configuration and workspace ID; Audio 3.1 uses the Qwen Audio WebSocket voice-conversation API and app-provided translation instructions. | `swift test --filter Qwen`; `./script/build_and_run.sh --verify` |
| Qwen Audio Filetrans | Settings > General > Qwen Audio File Transcription | `QwenAudioFileTranscriptionView`, `QwenAudioFileTranscriptionService` | A user-provided public HTTPS audio URL is sent to QwenCloud. QwenCloud fetches the file and returns an asynchronous task result. This workflow does not upload local audio files. | `swift test --filter QwenAudioFileTranscriptionServiceTests`; `./script/build_and_run.sh --verify` |
| Translated speech model selection | Main window bottom-right text-translation speech picker; Settings > General > Voice Output | `SpeechSynthesisModel`, `ProcessingModePicker`, `GeminiSpeechOutput`, `TranslationSessionStore.speakTranslatedDeltaIfNeeded` | Apple system speech and Gemini 3.8 TTS are selected in the separate text-translation speech picker. Gemini TTS is not a Gemini Live model and is not used for realtime provider audio. | `swift test --filter GeminiSpeechOutputTests`; `./script/build_and_run.sh --verify` |
| Single running app instance | Finder, Dock, and the local build/run launcher | `LSMultipleInstancesProhibited`, `script/write_info_plist.sh`, `script/build_and_run.sh` | Launch Services permits only one AirTranslate instance; the local builder does not kill or force-spawn an instance and stops before replacing the app bundle if AirTranslate is already running. | `script/verify_packaging_permissions.sh`; inspect generated local and release Info.plists |

# AirTranslate 1.12.0 릴리즈 검증

- 버전/빌드: 1.12.0 / 1120. 사용자 요청의 “하네스 릴리즈”가 master 직접 게시, 태그, GitHub Release 업로드를 승인한다.
- 범위: Qwen Audio 3.1 Realtime Plus를 Qwen LiveTranslate의 대체 모델로 추가하고, Qwen Audio 3.1 ASR Flash Filetrans의 공개 HTTPS URL 전사 UI를 추가했다. 기존 Qwen3.8 LiveTranslate는 유지한다.
- 적용 보정: Realtime Plus와 Filetrans는 싱가포르 API 키만 요구하고 workspace ID를 요구하지 않는다. Qwen3.8은 workspace ID 요구를 유지한다. Realtime Plus 요청에는 `Authorization`만 포함되며 workspace 헤더를 보내지 않는다.
- 보존: 기존 1.11.0 버전 자산 4개를 패키지 재생성 전후 보존하고 SHA-256을 확인했다. 미추적 `docs/release/1.8.0-verification-report.md`는 사용자 변경으로 남겨 두고 스테이지하지 않았다.

## 잔여 경계

- 실제 QwenCloud 계정 인증·접근 권한·과금·전사/번역 품질·지연은 미검증이다.
- Filetrans task polling 문서에 GET/POST 예시가 혼재해 있어 live task submission/poll/result 동작은 확인하지 않았다. 제공자가 반환한 결과 URL의 host allowlist는 없지만 결과 요청에는 Qwen Authorization 헤더를 전달하지 않는다.
- 배포 앱은 기존 방식대로 ad-hoc 서명·미공증이다.
- `hdiutil`에서 구형 attach/create 명령 사용 중단 예정 경고가 나왔지만 이미지 무결성 검증과 마운트 검사는 통과했다.

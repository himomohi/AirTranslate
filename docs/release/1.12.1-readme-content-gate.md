# 1.12.1 README meaning gate

The public product theme is single-instance app launch. Each localized README describes that behavior. The developer build harness change is recorded as release-note-only because it affects maintainers running the local build script, not packaged app users.

| Public theme | README.md | README.ko.md | README.ja.md | README.zh-CN.md | Release-notes-only reason |
| --- | --- | --- | --- | --- | --- |
| AirTranslate runs as a single app instance and a second launch returns to the existing app | `keeps the app to a single running instance` | `앱이 한 번에 하나의 인스턴스만 실행되도록 합니다` | `アプリを一度に1つのインスタンスだけで実行します` | `让应用一次只运行一个实例` | n/a |
| Local build-and-run stops before replacing an active app rather than killing or force-opening it | n/a | n/a | n/a | n/a | This is developer tooling behavior in `script/build_and_run.sh`; packaged app users do not run this script. It is documented in the 1.12.1 release notes and changelog. |

The `README_CONTENT_CHECKS` list in [README-CONTENT-CHECKS-1.12.1.env](README-CONTENT-CHECKS-1.12.1.env) contains the localized needle for the user-facing theme in all four READMEs. Release headings and download links are checked separately by the update-set audit.

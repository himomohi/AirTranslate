## 포함된 변경

설정에서 기본 Apple 시스템 음성, Gemini 3.8 Flash TTS, Gemini 3.8 Flash-Lite TTS를 고를 수 있으며 선택은 저장·복원된다. Gemini 음성은 Keychain의 기존 Gemini 키를 사용하고 안정된 번역 텍스트만 전송한다. 실시간 오디오 제공자가 이미 음성을 생성하는 세션에서는 로컬 Gemini 합성을 하지 않는다. API 키 요청은 ephemeral 세션으로 보내고 리다이렉트를 거부한다. Qwen Audio 3.1 선택지와 `LSMultipleInstancesProhibited=true` 단일 인스턴스 설정도 배포 앱에서 유지된다.

모델 이름과 API 사용 형식은 Google의 [Gemini 3.8 Flash TTS 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts), [Flash-Lite TTS 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts), [음성 생성 안내](https://ai.google.dev/gemini-api/docs/speech-generation)와 대조했다.

## 검증 경계

Gemini 계정 인증, 과금, 데이터 보존 정책, 음성 품질, 실시간 지연, 할당량과 Google 서비스 가용성은 실계정 API 호출 없이 검증하지 않았다. 공개 앱은 ad-hoc 서명이고 Apple 공증을 받지 않았다. 후보 1.13.0 UI의 실제 앱 실행 확인도 기존 실행 중인 싱글톤을 보존하느라 수행하지 않았다.

## 게시용 문구

AirTranslate 1.13.0 adds a choice of Apple system speech, Gemini 3.8 Flash TTS, or Gemini 3.8 Flash-Lite TTS for translated output. Gemini TTS uses the API key stored in macOS Keychain and sends stable translated text for speech generation. [Download AirTranslate 1.13.0](https://github.com/himomohi/AirTranslate/releases/tag/v1.13.0).

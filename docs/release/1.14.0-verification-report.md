## 포함된 변경

메인 화면 우측 하단 피커에서 제공자를 전환하고 해당 제공자의 모델을 선택할 수 있다. Apple, OpenAI, Gemini, Qwen, Nari의 선택 가능한 모델을 표시하고, 모델 이름을 피커 배지에 보여 준다. 현재 번역 흐름에서 지원하면 같은 팝오버에서 번역 음성 모델도 선택한다. 제공자 목록과 설정 바로가기는 유지하며, 목록이 길어져도 모델 선택 영역이 팝오버 안에 보이도록 했다.

고정 `airtranslate-release-operator` 역할은 사용자의 지시에 따라 일반 하위 에이전트로 교체했다. `gpt-6-luna`, max 추론의 하위 에이전트는 버전·릴리즈 문서만 준비했고, 메인이 코드 통합·검증·게시를 맡았다.

## 검증 경계와 흡수한 오류

실제 OpenAI, Gemini, Qwen, Nari 등 외부 제공자의 인증·과금·음성 품질·지연은 확인하지 않았다. Qwen 런타임 선택은 API 키가 없어 미검증이다. 앱은 ad-hoc 서명이고 Apple 공증을 받지 않았다. 기본 `swift test` 병렬 실행의 시간 민감 실패는 이미 CI가 사용하는 `--no-parallel` 명령으로 확인했다. 체크섬 검사는 basename manifest가 기준으로 삼는 `Release/product` 경로에서 다시 통과했다. 초기 아카이브 스캔의 재귀 정리 구문은 도구가 실행 전 차단해, 자동 정리를 제거한 스캔으로 통과했다. 원격 검사 스크립트의 초기 zsh 문자열 분할 오류는 명시 파일 인자를 사용하는 Bash 순회로 고쳐 6개 자산을 모두 검사했다. `hdiutil`의 legacy 명령 deprecation 경고는 있었지만 디스크 이미지 검증·마운트는 통과했다.

# AirTranslate 1.9.0 Security Gate - 2026-09-16

Status: PASS with bounded residual risk.

Version/build: 1.9.0/build190.

This report supersedes the earlier pre-GA and GA-only artifact passes. After the
Nari Free Public Beta sunset fix, a later recovery UI fix changed the source
binary in `TranslationSessionStore`; the final artifact evidence below is the
recovery-final rebuild.

Scope:

- Current uncommitted 1.9.0 Nari STT, GA model compatibility, API-key UI, readiness/session lifecycle, README/privacy/release-note wording, and the legacy-free recovery overlay fix.
- Fresh local artifacts in `Release/product`: `AirTranslate-1.9.0-190.zip`, `AirTranslate-1.9.0.zip`, `AirTranslate.dmg`, `AirTranslate-1.9.0.dmg`, and both `.sha256` files.
- No live provider credentials were used. No GitHub push, tag, release mutation, or remote asset scan was performed in this gate.

## Findings

Critical: none.

High: none.

Medium: none.

Low / residual:

1. Artifacts remain ad-hoc signed and not Apple-notarized. This is disclosed in `README.md`, localized READMEs, `Release/GITHUB-RELEASE-1.9.0.md`, and `docs/GETTING-STARTED.md`. This is not a security blocker for the current open-source distribution model, but it remains a distribution trust boundary.
2. Real Nari account authorization, quota, live connectivity, accuracy, and latency remain unverified because this gate did not use live credentials or real audio. Current public wording already states this boundary.
3. Remote GitHub asset verification remains pending until after publication. Local tag/push/upload is not blocked by this security gate, but downloaded release assets must be scanned after upload.
4. The release artifact binary contains the string `Authorization`, which is expected because the app constructs an HTTP authorization header at runtime. No token-shaped value, private key, `.env`, certificate, or provisioning profile was found.
5. LICENSE and NOTICE are present inside the app bundle resources in both ZIP variants and both DMGs. If the release operator requires top-level LICENSE/NOTICE files beside `AirTranslate.app`, packaging should add them; the current local security gate did not treat bundle-resource placement as a blocker.

Resolved GA compatibility risk:

- The Free Public Beta `:free` endpoints are preserved for existing saved settings but cannot start.
- Existing `:free` settings are not silently changed to paid GA models.
- A blocked legacy selection opens General Settings with the action title `Choose GA Nari model`.
- Newly selected GA models show explicit credit and hourly-cost copy before use.
- Moving from blocked legacy to GA or Apple default clears the legacy blocker overlay/status without clearing unrelated errors.

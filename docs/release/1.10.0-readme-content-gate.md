## Audit 입력 문자열

### README.md

- Grok Voice Transcribe 2.0
- Add your own key under **Settings > API Keys > SpaceXAI (xAI)** and select **Grok STT** in General settings. The key is stored separately in macOS Keychain; audio is sent directly to xAI when capture starts. Provider charges and account limits apply.
- Grok starts with **original-only captions and automatic spoken-language recognition**. Apple Mode remains the default, and Apple Translation can be enabled separately. Live xAI authentication, transcription accuracy, and latency have not been verified with a real account.
- Completed Grok utterances are not duplicated
- Saved transcripts exclude provisional captions
- clears the Grok missing-key notice

### README.ko.md

- Grok Voice Transcribe 2.0
- **설정 > API 키 > SpaceXAI (xAI)**에 본인의 키를 저장하고 일반 설정에서 **Grok STT**를 선택하세요. 키는 별도 macOS Keychain 항목에 저장되며, 캡처를 시작하면 오디오가 xAI로 직접 전송됩니다. 제공자의 이용 요금과 계정 한도가 적용됩니다.
- Grok은 **원문 전사와 음성 언어 자동 인식**으로 시작합니다. Apple 기본 모드는 유지되며 Apple Translation 번역은 별도로 켤 수 있습니다. 실제 xAI 계정 인증·전사 정확도·지연은 아직 검증하지 않았습니다.
- 확정 발화를 중복 추가하지 않으며
- 저장 파일에서 임시 자막과 번역 상태 안내를 제외합니다
- Grok 키 누락 안내가 해제됩니다

### README.ja.md

- Grok Voice Transcribe 2.0
- **設定 > APIキー > SpaceXAI (xAI)** に自分のキーを保存し、一般設定で **Grok STT** を選択します。キーはmacOS Keychainの専用項目に保存され、キャプチャ開始時に音声がxAIへ直接送信されます。プロバイダーの利用料金とアカウント制限が適用されます。
- Grokは **原文のみの字幕と音声言語の自動認識** で開始します。Apple Modeは標準のままで、Apple Translationによる翻訳を別途有効にできます。実際のxAIアカウントでの認証・認識精度・遅延は未検証です。
- 確定済み発話を重複追加せず
- 保存ファイルから暫定字幕と翻訳状態の案内を除外します
- Grokのキー未設定案内が解除されます

### README.zh-CN.md

- Grok Voice Transcribe 2.0
- 在**设置 > API 密钥 > SpaceXAI (xAI)**中保存自己的密钥，然后在常规设置中选择 **Grok STT**。密钥单独保存在 macOS Keychain 中，开始捕获时音频会直接发送到 xAI。提供方的费用和账户限制适用。
- Grok 默认以**仅原文字幕和自动识别语音语言**开始。Apple Mode 仍为默认模式，可另行启用 Apple Translation 翻译。尚未使用真实 xAI 账户验证认证、转写准确度和延迟。
- 不会重复添加已确认的语句
- 保存文件会排除临时字幕和翻译状态提示
- 清除 Grok 密钥缺失提示

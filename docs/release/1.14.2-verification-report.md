## 변경 내용

메인 화면 우측 하단의 모델 선택에서 공급자별 모델을 고르고, 실시간 번역과 원문 전사를 구별하도록 모델 설명과 그룹을 정리했다. Gemini 3.8 TTS는 실시간 모델 목록과 분리해 텍스트 번역 음성 출력에서만 사용한다고 표시한다. 모델 문서 조사에 따라 Qwen Audio 3.1 Realtime Plus는 번역 지시를 받아 음성 응답을 만들 수 있는 양방향 실시간 음성 대화 모델로, Qwen3.8 LiveTranslate는 전용 실시간 번역 모델로, Qwen Audio 3.1 ASR Flash Filetrans는 공개 HTTPS 오디오 URL을 처리하는 비동기 전사 모델로 구분했다. Azure MAI는 5초 WAV를 REST API로 보내는 전사 경로로 표기했다. 상세 근거는 [모델 기능 분류 문서](../model-capability-classification-2026-09-24.md)에 기록했다.

## 게시·검증 경계

`a7bc341266a381989f8caa12471514a7a37dd91b`를 `master`에 직접 push하고 annotated `v1.14.2` 태그와 6개 자산을 공개했다. GitHub push 응답에는 변경을 PR로 해야 한다는 규칙 우회 알림이 포함됐지만 push와 후속 CI가 성공했다. 보호 규칙은 변경하지 않았다. 검증 기록만 담은 후속 커밋이 추가되며 릴리즈 태그는 위 소스 커밋을 계속 가리킨다.

모든 앱 자산은 ad-hoc 서명이고 Apple 공증을 받지 않았다. 제공자 계정 인증, 유료 사용, 실시간 캡처, 번역·음성 품질과 지연은 검증하지 않았다. Qwen API 키가 없어 해당 제공자의 실제 UI 선택과 연결은 미검증이다.

## 하네스 반복과 실패 흡수

첫 `build_and_run.sh --verify`는 기존 앱이 실행 중이어서 중단됐다. Computer Use로 대상 `dist` 앱을 닫고 재실행해 통과했다. 이름으로 앱을 조회하면 구 `/Applications` 복사본도 선택될 수 있음을 확인해 이후에는 정확한 `dist/AirTranslate.app` 경로에 바인딩했다. 프로세스 검사도 경로 정규식 대신 `pgrep -x AirTranslate`와 실행 경로를 함께 사용했다. 이 구분으로 구 앱의 인스턴스 설정과 이번 릴리즈 앱의 `LSMultipleInstancesProhibited=true` 검증을 혼동하지 않았다.

첫 update-set 감사가 네 README의 오래된 ZIP 링크를 경고해 네 언어 링크를 모두 1.14.2로 맞춘 뒤 다시 통과했다. 첫 checksum 호출은 product 폴더 기준 파일명을 저장소 루트에서 찾지 못해 `Release/product`로 이동한 뒤 통과했다. 첫 아카이브 스캐너 호출의 셸 이스케이프 오류는 인자 인용을 고쳐 재검사해 통과했다. `hdiutil` deprecated 경고는 기능 오류로 판단하지 않았고 로컬·원격 이미지 검증은 성공했다.

GitHub CLI에서 지원되지 않는 `isLatest`·`url` JSON 필드 조회는 실패했으며, `gh release list --json tagName,isLatest,isDraft`로 Latest 상태를 확인했다. URL 검사의 첫 출력이 리다이렉트된 임시 서명 URL을 포함할 수 있어 재검사는 상태 코드만 출력하도록 바꿨다. 최종 공개 URL 9개는 모두 HTTP 200이다.

## UI 및 잔여 경계

- 실제 배포 앱에서 Qwen 모드의 키 없는 선택 비활성화와 설정 버튼 활성, Qwen 키/싱가포르 워크스페이스 설정 이동, 정보 화면 1.11.0(1110)을 확인했다.
- 플로팅 자막 설정 진입 시 `Sky Computer Use native pipe closed before response`가 재발했다. AirTranslate 프로세스는 계속 실행 중이며 이 실패는 실제 자막 설정 조작 PASS로 처리하지 않는다. 동일 화면 반복 호출·권한 우회·외부 GUI 도구 전환을 하지 않았다.
- 자막 렌더링·스타일·출력 선택 회귀는 전체 테스트에 포함되어 통과했다. 실제 해당 설정의 클릭·VoiceOver·hover 팝업과 실음성은 미검증이다.
- 실제 Alibaba Cloud 인증·과금·할당량·번역 품질·지연은 미검증이다. 제공자 키를 읽거나 입력하지 않았고 유료 API 호출을 하지 않았다.
- 배포물은 기존 정책대로 ad-hoc 서명·미공증이며, 신규 사용자의 Gatekeeper/TCC 허용과 업데이트 간 권한 승계는 별도 경계다.

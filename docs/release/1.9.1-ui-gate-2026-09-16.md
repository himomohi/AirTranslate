## 도구 경계와 접근성

처음 ColorPicker의 클릭·Show color panel 뒤 도구가 Settings/Main 창을 우선 노출했다. 메인 창을 닫자 이미 열려 있던 실제 Colors 창과 color wheel·slider·palette·pencils가 드러났다. 이는 색상 선택창이 열리지 않는 제품 실패로 판정하지 않는다. ColorPicker 자체 색 선택 조작 대신 정밀 #RRGGBB 입력 경로의 실제 적용·저장·복원을 검증했다.

Settings의 Tab 포커스가 색상 well까지 이동했고 HEX 입력의 Return 적용을 확인했다. 플로팅 handle의 AX Increment는 실제 크기를 변경했다. 직접 방향키 이벤트는 크기 변화가 없어 해당 입력 경로를 PASS로 세지 않는다. VoiceOver 실제 낭독은 미검증이다. 임의 사용자 색상은 대비가 낮을 수 있다.

UI 입력 직전의 현재 창 캡처를 좌표·현재 상태 확인에 사용했다. 각 드래그 결과에 따라 다음 입력이 달라져 순차 원본 캡처로 확인했으며 여러 정적 화면 비교 보고서나 컨택트 시트 검증으로 주장하지 않는다.

## 복원 기준과 서비스 경계

메인: Apple, 영어→한국어, PC 소리, 번역, 음성 출력 끔, 플로팅 끔. 플로팅: 번역, 보통30pt,3줄, 안정화 기본, 가운데, 항상 위 켬. 새 외형은 기본값으로 초기화했고 창720×170을 확인했다. Cmd+Q 후 정확한 dist 경로를 다시 열어 준비됨과 플로팅 끔을 확인했다.

화면 문구는 앱의 실제 대기 문구와 설정 미리보기다. 실제 오디오·클라우드 연결·YouTube Live 스트림 전사 검증으로 주장하지 않는다. 키·권한 변경은 수행하지 않았다.

## 수정 내용

기존 Gemini 모델 메뉴에는 실시간 번역·전사 두 항목만 있었고 Gemini 3.8 TTS 모델은 별도 음성 설정에 있었습니다. Gemini 실시간 모드에서는 그 별도 선택기까지 숨겨졌습니다. 이제 메인 화면 우측 하단의 Gemini 모델 메뉴에 `실시간 모델`과 `번역 음성 모델` 그룹을 표시합니다. Gemini 3.8 Flash TTS와 Flash-Lite TTS의 선택 상태는 실시간 모델과 독립적으로 저장됩니다. 번역 음성 선택은 실시간 모드 중에도 유지되며 텍스트 번역 흐름에서 사용됩니다.

## 검증 경계와 하네스 성숙도

Gemini 계정 인증·과금·실제 음성 생성 품질·지연은 검증하지 않았다. UI 검증은 모델 선택과 저장값 복원까지이며 캡처를 시작하거나 유료 API를 호출하지 않았다. 앱은 ad-hoc 서명이고 Apple 공증을 받지 않았다. 공개 자산에 포함된 서명·공증 안내는 이 배포 한계를 그대로 밝힌다.

첫 update-set 감사는 README needle 안의 ASCII 세미콜론을 항목 구분자로 해석해 실패했다. 영문 문장을 나누고 저장 동작과 실시간 자체 음성을 별도 주제로 분리해 네 README의 12개 의미 검사로 통과시켰다. 첫 아카이브 보안 스캔은 macOS에 없는 `/usr/bin/rg`를 지정해 중단됐다. PATH에서 찾은 `rg`로 로컬·원격 ZIP/DMG를 다시 스캔해 통과했다. zsh에서 읽기 전용 특수 변수 `status`를 검사 변수로 사용한 링크 검사는 `http_code`로 바꾸고 9개 URL을 다시 확인했다. `gh release view`의 JSON 필드에 `isLatest`가 없어 `gh release list` 결과로 Latest 상태를 확인했다. `hdiutil`은 deprecated 경고를 출력했지만 이미지 검증·읽기 전용 마운트·분리는 모두 성공했다.

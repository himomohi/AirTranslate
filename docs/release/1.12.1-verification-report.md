## Residual boundaries

- This release changes macOS app process uniqueness. It does not verify Qwen provider authentication, billing, audio capture, translation/transcription quality, or latency.
- Window foreground focus on a second launch was not measured; the verified behavior is that a second process was not created.
- Release assets remain ad-hoc signed and not Apple-notarized. The local packaging command emitted an `hdiutil` legacy-command deprecation warning; disk-image verification passed.

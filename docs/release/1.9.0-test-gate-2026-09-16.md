# AirTranslate 1.9.0 테스트·패키지 게이트

검증일: 2026-09-16. 범위: 먼저 출시하는 Nari STT, GA 모델 안내·종료된 Free Beta 시작 차단·모델 전환 시 오류 해제, 통합 API 키 UI의 1.9.0 / build 190. Issue #18은 이 검증 범위에 포함하지 않는다. 아래 결과는 GA 및 모델 전환 후 오류 해제 보정을 반영한 최종 빌드이며 이전 테스트·자산 증거를 대체한다.

전체 테스트와 CI에 정의된 두 반복 검사는 기본 병렬 동작을 유지했다. GA 및 오류 해제 보정 후 집중 회귀 검사와 전체 315개 검사를 다시 수행했다. 종료된 `:free` 모델의 복원 유지·시작 차단·명시적 GA 모델 선택·GA/Apple 전환 시 이전 오류와 복구 안내 해제·GA 모델 wire ID를 포함한다. 복원 세션의 `hasNariAPIKey`도 명시해 로컬 Keychain 유무에 의존하지 않는다. 대상과 구현이 바뀌지 않은 기존 CI 반복 검사 40회는 같은 날의 성공 증거를 재사용하며 최종 원격 CI에서 다시 실행한다.

새 Nari 세션 테스트는 UUID별 `UserDefaults` suite와 임시 전사 디렉터리를 사용하며 종료 시 정리한다. Nari 소켓 테스트는 주입한 stub으로 프로토콜·수명주기를 검사한다. API 키 테스트는 query 및 입력 검증을 확인한다. 이 결과는 실제 Nari 계정 인증·음성 입력·클라우드 접속 성공을 증명하지 않는다.

## 환경과 실행

- 호스트: arm64, macOS 27.0 (26A428).
- Swift: Apple Swift 6.4 (`swiftlang-6.4.0.30.4`, `clang-2100.3.30.1`).
- Xcode 선택은 각 명령의 `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer`에 한정했다.
- 앱 실행 확인 경로: `/Users/appcaster/Dev/AirTranslate/dist/AirTranslate.app/Contents/MacOS/AirTranslate`.
- GA 및 오류 해제 보정 반영 재실행 직후 PID 1584와 앱 Info.plist의 1.9.0 / 190을 확인했다. UI 검증은 Coordinator의 별도 `1.9.0-ui-gate-2026-09-16.md`에 기록한다.

실행한 프로젝트 명령:

```sh
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test --filter legacyFreeSelectionRestoresButBlocksStartUntilGAModelIsExplicitlySelected
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift build -c release
./script/verify_packaging_permissions.sh
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer BUILD_CONFIGURATION=release ./script/build_and_run.sh --verify
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer ./Release/build_open_source_release.sh all
```

아래 두 명령은 각각 20번 실행했으며 모든 실행의 exit 0, 실제 테스트 수 2개/1개, `No matching test cases were run` 부재를 검사했다. 이는 `.github/workflows/release-verify.yml`의 필수 반복 검사와 같은 필터 및 횟수이다.

```sh
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test --filter 'orphanTerminalRecoversAfterElapsedMetadataGrace|terminalWithMissingPredecessorRecoversAfterElapsedMetadataGrace'
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer swift test --filter 'restoredGeminiTranscriptionPreservesFloatingCaptionPreference'
```

자산별로 `ditto -x -k`, `hdiutil verify`, `hdiutil attach -readonly -nobrowse -mountpoint`, `codesign --verify --deep --strict --verbose=2`, `codesign -dvv`, `codesign -d --entitlements :-`를 실행했다. Info.plist와 entitlements는 plist 파서로 확인했으며, 압축 해제한 앱의 모든 파일 해시를 원본 product 앱과 비교했다. 두 DMG의 `/Applications` 링크도 확인했다. 검사 마운트는 해제했고 임시 추출 폴더는 정리했다.

## 실패 처리와 남은 경계

- GA 보정 전 보안 검사와 테스트 검사가 동시에 DMG를 마운트하던 중 versioned DMG에서 `hdiutil: attach failed - 리소스 사용 중` exit 1이 한 번 발생했다. 마운트 소유권을 테스트 담당자에게 모으고, 활성 이미지 부재 확인 후 단독 재실행해 해소했다. GA 최종 자산은 처음부터 테스트 담당자가 두 DMG의 검사·해제를 순차 완료한 뒤 보안 담당자에게 전달하는 방식으로 검증했다.
- GA 복원 테스트는 첫 전체 실행에서 통과했지만 코드 검토로 복원한 세션의 실제 Keychain 상태 의존성이 발견됐다. `restored.hasNariAPIKey = true`를 명시하는 test-only 보정을 적용하고 해당 테스트를 다시 통과시켰다. 복원한 별도 인스턴스에도 외부 상태를 명시해야 한다는 회귀 검증 규칙으로 흡수한다.
- GA UI 재검증에서 종료된 Free Beta의 시작 오류가 GA/Apple 전환 뒤에도 남는 결함을 확인했다. 모델 전환 시 종료된 Free Beta에 해당하는 실패 상태만 해제하도록 보정하고 같은 회귀 검사에 GA 및 Apple 전환 후 `captureStartFailureMessage`, `captureStartRecoveryAction`, 준비 상태 검사를 추가했다. 집중 검사·전체 검사·release 빌드·재실행·모든 자산 검증을 새로 수행했다.
- macOS 27의 `hdiutil`은 create/attach/detach 명령 폐기 예정 경고를 출력했으나 자산 생성과 최종 검증은 성공했다. 이 작업에서 기존 프로젝트 스크립트를 바꾸지 않았다.
- 공개용 앱은 ad-hoc 서명이다. Developer ID 서명, notarization, 새 사용자 기기의 Gatekeeper 통과, macOS 26에서의 실제 실행을 검증했다고 주장하지 않는다.
- 실제 클라우드 계정·사용자 키 입력·오디오 캡처는 이 담당자의 범위에서 수행하지 않았다. 보안 게이트 및 원격 업로드 이후 다운로드 검증은 별도 결과와 결합해야 한다.
- source 파일 변경·커밋·push·tag·GitHub 게시를 수행하지 않았다. 본 보고서와 생성 자산만 담당했다. 하네스 성숙도 기록 통합은 Coordinator가 수행한다.

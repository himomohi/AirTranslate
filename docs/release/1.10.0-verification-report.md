## 실행한 검사

- `swift test --no-parallel`: 366개/39 suites PASS. 기존 병렬 checkpoint 타이밍 실패 이력은 47회차 기록에 보존했다. 이번 실행에서 제품 timeout을 변경하지 않았다.
- `./Release/build_open_source_release.sh all`: release 빌드·ZIP·DMG 생성 PASS.
- `./script/verify_packaging_permissions.sh`: 마이크 권한, Hardened Runtime, release/debug entitlement 구분 PASS.
- `BUILD_CONFIGURATION=release ./script/build_and_run.sh --verify`: 새 앱 실행 경로 검사 PASS.
- 이후 최종 `Release/product/AirTranslate.app`을 `dist/AirTranslate.app`에 동일 바이트로 복사하고 `diff -rq`, strict codesign, 실제 실행·버전 화면을 확인했다.
- `PUBLIC_RELEASE=1` update-set audit: 버전, 6자산, 네 언어 24개 의미 확인 문자열, 저장소·릴리즈·다운로드 링크 포함 PASS. 이 정적 링크 검사는 원격 HTTP 성공과 구분한다.
- 기존 CI 비밀정보 검사에 xAI 키 형식과 XAI 키 할당 패턴을 추가했다. 가짜 fixture 두 종류 탐지와 정상 문구 비탐지 PASS; 비밀값은 출력하지 않았다.
- `git diff --check`: PASS.

## 파일과 잔여 경계

- Grok 모델·Keychain·WebSocket·세션·설정 UI·테스트와 기존 구현 문서, 메타데이터, CHANGELOG, VERSION-HISTORY, 네 README, 개인정보 안내, 시작 안내, 기능 맵, CI 비밀 패턴, 릴리즈 노트·검증 기록·성숙도 기록이 이번 릴리즈 범위다.
- 생성 `Release/product`, `dist`, `.build`는 Git에서 제외한다. 기존 미추적 `1.8.0-verification-report.md`는 유지하고 커밋에 포함하지 않는다.
- 실제 xAI 계정 인증, 유료 음성 전사, 인식 정확도, 지연, 계정 한도는 미검증이다. 이 한계를 네 README와 릴리즈 노트에 명시했다.
- ad-hoc 서명·미공증 정책을 유지한다. 새 사용자 Gatekeeper/TCC, macOS 26 실제 UI와 VoiceOver 낭독은 별도 경계다.
- 최종 화면은 Apple·영어→한국어·PC 소리·번역·음성/플로팅 꺼짐·준비됨으로 유지했다.

## GA 모델 전환·오류 복구 최종 검증

무료 베타 종료 안내 확인 후 GA 모델 호환성을 수정하여 앱을 다시 빌드했다. 아래는 오류 해제 수정까지 반영된 마지막 `--verify` 번들(PID 1584, 1.9.0/190)의 Computer Use 접근성 상태 검증이다.

- 새 Nari 선택: `Qwen3-ASR Fast · GA · credits`, 유료 크레딧 사용·입력 오디오 시간당 가격·무료 베타 종료 일정이 일반 설정에 표시됨.
- 레거시 Free 모델을 명시적으로 선택하면 해당 값과 ‘보존되지만 시작할 수 없음’ 안내가 표시됨.
- 레거시 선택 상태에서 시작을 눌렀을 때 캡처가 시작되지 않고 `Nari GA 모델 선택` 복구 버튼이 표시됨. 코드의 readiness guard와 테스트가 키 조회·네트워크 연결 이전 차단을 확인한다.
- 복구 버튼은 일반 설정의 Nari 모델 선택으로 이동함.
- GA Fast를 직접 선택한 뒤 메인 화면에서 이전 실패 안내와 복구 버튼이 사라지고 `준비됨`으로 복원됨. GA 상태에서 시작/외부 전송은 하지 않음.
- Apple 기본 모드로 복원한 뒤에도 `준비됨`, 영어→한국어, PC 소리, 번역, 음성 출력 끔, 플로팅 자막 끔 상태를 확인함.

처음 GA 재검증에서 모델을 바꿔도 이전 오류 안내가 남는 회귀를 발견했다. `nariTranscriptionModel` 변경 시 레거시 전용 실패만 정리하도록 고쳤고, GA/Apple 두 전환의 회귀 assertion을 추가한 뒤 새 번들에서 위 흐름을 다시 통과했다. 전체 테스트는 마지막 테스트 게이트의 315개/36 suites 결과를 따른다. 최초 위 표의 Free 모델 선택 관찰은 수정 전 증거이며 최종 모델 계약은 이 절이 대체한다.

# AirTranslate 1.9.0 게시 검증

상태: **게시 완료 — 로컬·원격 게이트 PASS**. 사용자 지시에 따라 기존 Nari·API 키 UI·README 정리를 먼저 **1.9.0/build190**으로 게시한 뒤 Issue #18을 별도 버전에서 진행한다. 이 보고서는 9월 13일 준비 기록을 보존한 채 9월 16일 재실행 증거를 모은다.

## 수용 기준

- Apple 기본값과 기존 선택형 엔진을 보존하고 Nari 전사와 통합 API 키 화면을 배포한다.
- 새 Nari 선택에 GA Fast 및 유료 크레딧 안내를 제공한다. 저장된 무료 모델은 보존·시작 차단하고, 설정에서 사용자가 직접 GA 모델을 선택해야 다시 시작할 수 있다.
- 네 언어 README, 변경 이력, 릴리즈 노트, 버전 및 여섯 개 배포 파일이 동일한 변경 내용을 가리킨다.
- 현재 소스의 자동 테스트·앱 재실행·보안·배포 파일 검사를 통과한 뒤 게시한다.
- 게시 후 원격 소스, CI, 다운로드 링크, 여섯 자산의 바이트/SHA-256 및 추출 보안 검사를 확인한다.

실행·재실행 명령과 종료 코드는 각 게이트 문서가 최종 근거다. 전체 도구체인은 프로세스별 `DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer`로 선택한다.

```sh
swift test
swift build -c release
./script/verify_packaging_permissions.sh
BUILD_CONFIGURATION=release ./script/build_and_run.sh --verify
./Release/build_open_source_release.sh all
hdiutil verify Release/product/AirTranslate.dmg
hdiutil verify Release/product/AirTranslate-1.9.0.dmg
codesign --verify --deep --strict --verbose=2 <검사 대상 앱>
git diff --check
```

CI의 메타데이터 grace 필터와 Gemini 복원 필터는 각각 20회 통과했다. 구현이 바뀌지 않은 이 필터들은 GA 보완 전 같은 날의 증거를 재사용하며 원격 CI에서도 다시 실행하여 통과했다. 공개 audit의 전체 인자와 48개 `README_CONTENT_CHECKS`는 [의미 대응표](1.9.0-readme-content-gate.md)와 `README-CONTENT-CHECKS-1.9.0.env`에 둔다. 소스·추출 자산 비밀 검사 명령은 보안 보고서, 파일별 크기·SHA-256은 테스트 보고서에 기록한다.

| 갱신 중인 검증 보고서의 본문은 새 결과, 해시는 이전 결과였음 | 이전 자산의 보안 PASS를 최종 자산 결과로 오인할 수 있음 | 담당자 완료 메시지·최종 manifest·증거 문서가 모두 같은 해시를 가리킬 때만 통합 PASS 처리 |

코디네이터가 [Nari 모델 및 요금 안내](https://docs.narilabs.com/models-and-pricing)에서 무료 베타의 2026-09-16 23:59 PT 종료 및 9월 17일 PT부터 `:free` 요청 중단, GA ID `qwen3-asr`·`qwen3-asr-fast`를 확인했다. 가격·지연 수치는 AirTranslate 실측으로 주장하지 않는다.

44회차는 41회차 Nari 구현, 42회차 키 UI, 43회차 준비 이후 실제 릴리즈 하네스 재실행이다. 이번 실행은 실제 게시와 원격 재다운로드 검증까지 완료했다.

## 실행 역할과 남은 경계

release-operator·security-auditor·test-verifier·report-writer 책임으로 작업을 분리하고 코디네이터가 최종 통합·실제 UI·게시를 담당한다. 커스텀 역할 정의의 모델은 고판단 역할 `gpt-5.5`(release `high`, security `xhigh`), 검증·보고 `gpt-5.3-codex-spark`(`medium`)이다. 지정 역할 실행이 지원되지 않은 범위는 기본 작업자가 메인 모델·추론 설정을 상속했다. 이 호출 인터페이스는 각 실행의 실제 백엔드 모델 ID와 추론 설정을 별도로 증명하지 않으므로 역할 정의를 실제 실행 모델 확인으로 대체하지 않는다.

실계정 Nari 인증·실음성 정확도·레이턴시·할당량, VoiceOver 실제 낭독, 배포본의 새 사용자 TCC 승계는 미검증이다. 공개 파일은 기존 정책대로 ad-hoc 서명이며 Apple 공증을 받지 않았다. LICENSE와 NOTICE는 각 앱 번들의 `Contents/Resources`에 포함한다. Issue #18의 기능 개선은 1.9.0 게시 다음 단계이며 이 보고서의 완료 범위가 아니다.
